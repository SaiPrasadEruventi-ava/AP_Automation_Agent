Adding an SAP Connector to Avagama

A step-by-step guide to connect standalone agents to an SAP system using the SAP NetWeaver RFC SDK 7.50 (the nwrfc750P_17 package you downloaded) via the node-rfc binding — plumbed into the existing tool-adapter framework.

SAP NW RFC SDK 7.50 · patch 17 Windows x64 node-rfc Multi-function tool adapter

1. What's actually inside nwrfc750P_17-70002755.zip

This is the SAP NetWeaver RFC SDK 7.50, patch level 17, Windows 64-bit. It is a native C/C++ library — not something Node.js can call directly. It's the low-level engine that language bindings (like node-rfc) load to talk to SAP over the RFC protocol. Contents after extraction (folder nwrfcsdk/):

FolderKey filesWhat it's for
lib/sapnwrfc.dll (8 MB), libsapucum.dll, icudt57.dll, icuin57.dll, icuuc57.dll, *.libThe runtime. These DLLs must be found on the OS load path at runtime. The ICU DLLs handle Unicode; sapnwrfc.dll is the RFC engine.
include/sapnwrfc.h, sapdecf.h, sapucrfc.hC headers. Needed only when node-rfc compiles from source (no prebuilt binary for your Node version).
bin/rfcexec.exe, startrfc.exeStandalone RFC utilities (not needed by the Node connector).
demo/sapnwrfc.ini, sflightClient.c, othersC samples. sapnwrfc.ini is a useful reference for every logon parameter.
doc/licenses.txt, release_notes.txtLicense terms + changelog (confirms 7.50.17).
⚠ Platform lockThis ZIP is the Windows x64 SDK. It works on your Windows EC2 host. If you ever run the backend on Linux (e.g. the Docker/alpine path), those .dlls are useless — you must download the matching Linux SDK (nwrfc750P_x-70002752.zip for Linux x86_64) from the SAP Support Portal instead. The connector code stays identical; only the native SDK differs.

2. How this fits into Avagama

Your standalone agents already have a clean, pluggable connector system in services/standaloneAgents/toolAdapters/ (Slack, Gmail, Google/Outlook Calendar, Outlook Mail, web search). Each connector is a small adapter module that the tool executor turns into LLM-callable functions. Adding SAP = adding one more adapter of exactly the same shape — no changes to the chat loop, the LLM plumbing, or the tool registry contract.

We'll build a multi-function adapter (like the calendar adapters) exposing three functions the LLM can call:

LLM functionWhat it doesUnderlying RFC
sap_pingTest the SAP connection, return system infoRFC_PING
sap_call_functionCall a whitelisted BAPI / function module with parametersAny allowed RFM, e.g. BAPI_MATERIAL_GET_DETAIL
sap_read_tableRead rows from an SAP table (fields + WHERE, row-capped)RFC_READ_TABLE
Design stance: read-first & whitelistedAn LLM deciding which SAP function to call is powerful and risky. This connector is read-oriented and whitelisted by default — sap_call_function refuses any RFM not explicitly listed in the tool's allowed_functions. Add write BAPIs (and BAPI_TRANSACTION_COMMIT) only deliberately, per agent.

3. Architecture at a glance

  User ↔ Standalone Agent (chat)
        │  LLM emits a tool_call:  { name:"sap_read_table", arguments:{...} }
        ▼
  toolExecutorService.dispatchToolCall()          services/standaloneAgents/toolExecutorService.js
        │  resolves name → adapter + StandaloneTool record
        ▼
  sapRfc.js  adapter  (matches: name contains "sap")   ← NEW FILE
        │  builds connection params from tool.config.extras
        │  decrypts SAP password via utils/tokenCipher
        ▼
  node-rfc  (npm)  ──loads──►  sapnwrfc.dll  +  icu*.dll     (SAP NW RFC SDK)
        │  RFC protocol over TCP  (sysnr → gateway port 33<nn>)
        ▼
  ╔══════════════════════╗
  ║   SAP S/4HANA / ECC  ║   BAPIs · function modules · tables
  ╚══════════════════════╝

Everything above node-rfc is your JavaScript. Everything from node-rfc down is the native SDK from the ZIP. The two are connected purely by environment variables that tell node-rfc where the DLLs live.

4. Install the SAP NW RFC SDK (the ZIP)

The SDK isn't "installed" like an MSI — you just place the folder somewhere stable and point two environment variables at it.

1
Extract the ZIP to a fixed, permanent location (avoid spaces in the path): 
# Windows — extract nwrfcsdk\ to:
C:\nwrfcsdk
# so you have  C:\nwrfcsdk\lib\sapnwrfc.dll  etc.
2
Set SAPNWRFC_HOME and add the lib folder to PATH so Windows can load the DLLs at runtime: 
# PowerShell (run as the user/service account that runs Node), persistent:
[Environment]::SetEnvironmentVariable("SAPNWRFC_HOME", "C:\nwrfcsdk", "Machine")
$p = [Environment]::GetEnvironmentVariable("Path","Machine")
[Environment]::SetEnvironmentVariable("Path", $p + ";C:\nwrfcsdk\lib", "Machine")
3
Install the Visual C++ runtime the SDK was built with. SAP NW RFC SDK 7.50 requires the Microsoft Visual C++ 2013 Redistributable (x64) present on the host (see SAP Note 2573790). Without it, loading sapnwrfc.dll fails with a cryptic "module not found".
⚠ Restart shells after setting env varsA running PM2 process will not see the new SAPNWRFC_HOME/PATH until it's restarted with a fresh environment: pm2 restart avagama-backend --update-env (or fully stop/start). This is the #1 cause of "it works in my terminal but not in the app".

5. Install the node-rfc binding

node-rfc is the npm package that bridges Node.js and the SDK. It ships prebuilt binaries for common Node/OS combinations; if none matches your Node version it compiles from source (needs the C++ build toolchain + the headers from include/, which is why SAPNWRFC_HOME must be set before install).

# from the backend project root, with SAPNWRFC_HOME already set:
npm install node-rfc
If it builds from sourceYou'll also need Python 3 and Visual Studio Build Tools (Desktop C++ workload) so node-gyp can compile. Prebuilt binaries avoid all of this — pin a Node LTS that node-rfc publishes binaries for to keep installs painless.

7. Create the adapter file

This is the whole connector. Drop it in services/standaloneAgents/toolAdapters/sapRfc.js. It follows the exact multi-function shape (matches + getLlmFunctions) used by the calendar/mail adapters, decrypts the SAP password with your existing tokenCipher, and enforces the whitelist + row caps.

services/standaloneAgents/toolAdapters/sapRfc.js 
/**
 * SAP RFC/BAPI tool adapter — multi-function shape.
 * Requires: SAP NW RFC SDK on the host (SAPNWRFC_HOME + lib on PATH) and `npm i node-rfc`.
 *
 * StandaloneTool record shape:
 *   type: "builtin"
 *   name: contains "sap"          (e.g. "SAP ERP")
 *   config.extras: {
 *     ashost, sysnr, client, lang,            // direct app server  (OR ...)
 *     mshost, msserv, group, sysid,           // ...message-server / load balancing
 *     user,
 *     passwd_enc,                             // AES-256-GCM blob from tokenCipher.encrypt()
 *     allowed_functions: ["BAPI_MATERIAL_GET_DETAIL", ...],  // whitelist for sap_call_function
 *     allow_read_table: true,                 // gate RFC_READ_TABLE (default true)
 *     max_rows: 100
 *   }
 */
let rfc = null;
try { rfc = require("node-rfc"); } catch (_) { /* surfaced at call time with a clear message */ }
const { decrypt } = require("../../../utils/tokenCipher");
const logger = require("../../../utils/logger");

function matches(tool) {
  if (!tool) return false;
  const name = (tool.name || "").toLowerCase();
  if (!name.includes("sap")) return false;
  return tool.type === "builtin" || tool.type === "webhook";
}

function _connParams(tool) {
  const x = tool?.config?.extras || {};
  if (!x.user || (!x.ashost && !x.mshost))
    throw new Error("SAP tool not configured: need user + ashost (or mshost) in config.extras");
  let passwd = x.passwd || "";
  if (x.passwd_enc) { try { passwd = decrypt(x.passwd_enc); } catch (e) { throw new Error("SAP password decrypt failed"); } }
  const base = { user: x.user, passwd, client: x.client || "100", lang: x.lang || "EN" };
  if (x.mshost) return { ...base, mshost: x.mshost, msserv: x.msserv, group: x.group || "PUBLIC", sysid: x.sysid };
  return { ...base, ashost: x.ashost, sysnr: x.sysnr || "00" };
}

async function _withClient(tool, fn) {
  if (!rfc) throw new Error("node-rfc not installed / SAP NW RFC SDK not found. See SAP connector guide.");
  const client = new rfc.Client(_connParams(tool));
  await client.open();
  try { return await fn(client); }
  finally { try { await client.close(); } catch (_) {} }
}

// 1 ── Ping / connection test
async function sapPing(tool) {
  return _withClient(tool, async (c) => {
    await c.call("RFC_PING", {});
    const i = c.connectionInfo || {};
    return { ok: true, connected: true, sysid: i.sysId, client: i.client, host: i.host, release: i.rfcRole };
  });
}

// 2 ── Call a whitelisted function module / BAPI
async function sapCallFunction(tool, args) {
  const x = tool?.config?.extras || {};
  const allowed = (Array.isArray(x.allowed_functions) ? x.allowed_functions : []).map(s => String(s).toUpperCase());
  const fm = String(args.function_name || "").toUpperCase();
  if (!fm) throw new Error("function_name is required");
  if (!allowed.includes(fm)) throw new Error(`Function '${fm}' is not in this tool's allowed_functions whitelist`);
  const params = (args.parameters && typeof args.parameters === "object") ? args.parameters : {};
  return _withClient(tool, async (c) => ({ ok: true, function: fm, result: await c.call(fm, params) }));
}

// 3 ── Read a table via RFC_READ_TABLE (gated + row-capped)
async function sapReadTable(tool, args) {
  const x = tool?.config?.extras || {};
  if (x.allow_read_table === false) throw new Error("RFC_READ_TABLE is disabled for this tool");
  const table = String(args.table || "").toUpperCase();
  if (!table) throw new Error("table is required");
  const fields = Array.isArray(args.fields) ? args.fields.filter(Boolean) : [];
  const where  = Array.isArray(args.where) ? args.where : (args.where ? [String(args.where)] : []);
  const cap    = parseInt(x.max_rows) || 100;
  const rowcount = Math.min(parseInt(args.max_rows) || 50, cap);
  const D = "|";
  return _withClient(tool, async (c) => {
    const res = await c.call("RFC_READ_TABLE", {
      QUERY_TABLE: table,
      DELIMITER:   D,
      FIELDS:      fields.map(f => ({ FIELDNAME: String(f).toUpperCase() })),
      OPTIONS:     where.map(w => ({ TEXT: String(w) })),
      ROWCOUNT:    rowcount
    });
    const cols = (res.FIELDS || []).map(f => f.FIELDNAME);
    const rows = (res.DATA || []).map(d => {
      const parts = String(d.WA).split(D);
      const o = {}; cols.forEach((cn, i) => { o[cn] = (parts[i] || "").trim(); }); return o;
    });
    return { ok: true, table, count: rows.length, columns: cols, rows };
  });
}

// ── Multi-function descriptors the LLM sees ──
function getLlmFunctions(tool) {
  const x = tool?.config?.extras || {};
  const allowed = Array.isArray(x.allowed_functions) ? x.allowed_functions : [];
  const fns = [
    { name: "sap_ping",
      description: "Test connectivity to the SAP system and return system info (sysid, client, host). Use to verify the SAP connection is alive.",
      parameters: { type: "object", properties: {} },
      execute: sapPing },
    { name: "sap_call_function",
      description: "Call a specific SAP function module / BAPI by name and return its result. Only whitelisted function modules are permitted" +
        (allowed.length ? ` (allowed: ${allowed.join(", ")})` : "") +
        ". Use to read SAP business data via the appropriate BAPI (e.g. material, customer, sales-order details).",
      parameters: { type: "object", required: ["function_name"], properties: {
        function_name: { type: "string", description: "SAP function module / BAPI, e.g. BAPI_MATERIAL_GET_DETAIL" },
        parameters:    { type: "object", description: "Import/table parameters as a JSON object matching the RFM signature." }
      } },
      execute: sapCallFunction }
  ];
  if (x.allow_read_table !== false) fns.push({
    name: "sap_read_table",
    description: "Read rows from an SAP table (RFC_READ_TABLE). Use when the user asks for records from a known table. Row-capped.",
    parameters: { type: "object", required: ["table"], properties: {
      table:    { type: "string", description: "SAP table name, e.g. MARA, KNA1, VBAK" },
      fields:   { type: "array", items: { type: "string" }, description: "Columns to return. Fewer/narrower fields avoid the 512-char row limit." },
      where:    { type: "array", items: { type: "string" }, description: "WHERE clauses in ABAP SQL, e.g. [\"MTART = 'FERT'\"]." },
      max_rows: { type: "integer", description: "Max rows (capped by tool config)." }
    } },
    execute: sapReadTable
  });
  return fns;
}

module.exports = { matches, getLlmFunctions };

9. Create the SAP tool record (with encrypted password)

A connector becomes usable by an agent when there's a StandaloneTool record attached to it. Store the SAP password encrypted (never plaintext) using the same tokenCipher the OAuth connectors use. One-off script:

scripts/createSapTool.js 
require("dotenv").config();
const { getModel } = require("../models/standalone/StandaloneTool");
const { encrypt } = require("../utils/tokenCipher");

(async () => {
  const Tool = await getModel();
  const doc = await Tool.create({
    agent_id:     "<AGENT_OBJECT_ID>",
    organization: "<ORG_OBJECT_ID>",
    created_by:   "<USER_OBJECT_ID>",
    type: "builtin",
    name: "SAP ERP",               // must contain "sap" → adapter.matches()
    description: "Read material, customer and sales-order data from SAP.",
    enabled: true,
    config: { extras: {
      ashost: "10.0.0.12", sysnr: "00", client: "100", lang: "EN",
      user:   "RFC_SVC_USER",
      passwd_enc: encrypt(process.env.SAP_SVC_PASSWD),   // AES-256-GCM blob
      allowed_functions: ["BAPI_MATERIAL_GET_DETAIL", "BAPI_CUSTOMER_GETDETAIL2"],
      allow_read_table: true,
      max_rows: 100
    } }
  });
  console.log("created SAP tool", doc._id.toString());
  process.exit(0);
})();

11. Deployment notes (EC2 / PM2)

  • Ship the SDK with the host, not the repo. The DLLs are ~60 MB and SAP-licensed — keep them in C:\nwrfcsdk on the server, not in git. Add nwrfcsdk/ and any local copy to .gitignore.
  • Env vars must reach the PM2 process. Set SAPNWRFC_HOME + PATH at the machine level and restart PM2 with --update-env, or add them to the PM2 ecosystem file's env block.
  • Match the platform. Windows EC2 → this Windows SDK. If you move the backend into the Linux Docker image, swap in the Linux SDK and set LD_LIBRARY_PATH=/usr/local/sap/nwrfcsdk/lib (or register via ldconfig).
  • Pin Node to a version with node-rfc prebuilds so redeploys don't trigger a source compile on the server.
  • Connection reuse. The adapter opens/closes a client per call (simple + safe). If SAP call volume grows, switch _withClient to a node-rfc Pool to avoid repeated logon cost.
  • Network path. The Node host must reach the SAP application server on the gateway port 33<sysnr> (e.g. sysnr 00 → 3300) — open that in the security group/firewall.

12. Security & licensing (read this)

⚠ SAP licensingThe SAP NW RFC SDK is SAP proprietary. Per the bundled license terms, you're granted usage in a development environment; deploying it in production with your application is valid only with sufficient SAP software licenses. Confirm your org's SAP license covers RFC/BAPI access before going live. Do not commit or redistribute the DLLs.
  • Dedicated least-privilege SAP user. Create a Communication/System user (not a dialog user) for RFC. Restrict its S_RFC authorization to only the function groups/modules you whitelist. It should be unable to run anything you didn't intend — defense in depth behind the code whitelist.
  • Encrypt the password at rest (done above via tokenCipher → passwd_enc). Never store passwd in plaintext in the tool record.
  • Keep it read-only by default. Write BAPIs mutate ERP data and usually require an explicit BAPI_TRANSACTION_COMMIT. Only add them to allowed_functions for agents that genuinely need them, and consider gating those behind a human-approval action.
  • Cap rows & fields. RFC_READ_TABLE has a 512-byte row-width limit and can be heavy — the adapter caps rows via max_rows; encourage the model to request specific fields.
  • Consider SNC (Secure Network Communications) for encrypted transport to SAP in production; it's configured via additional connection parameters.
