SAP verification guide — every demo case

For each case: what to show in SAP before processing (proving the mismatch is real ERP data), what to click on the AP dashboard, and exactly where to confirm the result in SAP afterwards — then how to reset. All PO, goods-receipt and amount values below were read live from SAP when this guide was generated (15 Oct 2026 13:36). Invoice document numbers (51000xxxxx) are new on every run — take them from the dashboard's SAP column.

Before you start

  1. Log on to SAP: open SAP Logon 750 → double-click New IDES S4HANA (65.2.76.131, instance 57, SID A4F) → Client 100 · your SAP user · Language EN → Enter.
  2. Start the AP dashboard: PowerShell in the project folder → uv run --no-project uvicorn api.index:app --reload --port 8000 → browse to http://localhost:8000.
  3. Check the green Live SAP bar on the Overview page (SID A4F, client 100).
  4. Click 🧪 SAP Demo Cases → Reset all demo cases so every case starts clean (it reverses/deletes any SAP invoice the agent created earlier). Every row's Current status must read Not run yet.
  5. In SAP, use the command field (top-left) — type /nME23N etc. and press Enter to jump between transactions.
Posting dates: SAP's MM posting periods in company code 1710 are open only up to 04/2026, so goods receipts and invoices carry posting date 30.04.2026; the real date is in the document date. This is expected — not an error.

Undo invoices manually in SAP — step by step (for SAP beginners)

The dashboard's Reset button does all of this for you automatically. Use these steps when you want to show it in SAP yourself, or clean up without the app. Important: you never reverse the purchase order — the PO and its goods receipt stay as they are. What gets undone is the supplier invoice the agent created against the PO.

First: is the invoice posted or parked?

You see…It is…How to undo it
Dashboard: “Posted in SAP 51000…” · MIR4 title bar says Display Invoice DocumentPosted (it is in the accounts)Reverse it with MR8M → section A
Dashboard: “Parked in SAP 51000…” · MIR4 title bar says Display Parked Invoice Document / status ParkedParked (a draft, not in the accounts)Delete it in MIR4 or MIR6 → section B

A · Reverse a POSTED invoice — transaction MR8M

#Do thisDetails
1In the SAP command field (top-left white box) type /nMR8M and press EnterScreen “Cancel Invoice Document” opens.
2Invoice Document No. = the posted number (e.g. 5100001732)Take it from the dashboard's SAP column / the run report.
3Fiscal Year = 2026
4Reversal Reason = 01Press F4 on the field to pick from the list — 01 = “Reversal in current period”.
5Posting Date = 30.04.2026Must be in an open MM period. If you use today's date SAP says “Posting only possible in periods 2026/04 and 2026/03” — just change the date.
6Optional: click Display Doc. to double-check it is the right invoice, then press F3 (Back)Shows vendor, amount, reference INV-Sxx-xxxx.
7Click Save (disk icon, or Ctrl+S) — some screens call it ReverseStatus bar at the bottom: “Document reversed with document number 51000xxxxx”. Write that number down — it is the reversal document.
8Check: /nMIR5 → Company Code 1710 → Reference INV-Sxx-xxxx → F8You now see two documents: the original and its reversal. Net effect is zero.
9Check: /nME23N → the PO → Item → Purchase Order History tabThe RE-L line now has a matching negative line (e.g. 20 and 20-) — see “Reading Purchase Order History” below.

Common messages: “Document already reversed” → nothing to do. “Posting period not open” → use 30.04.2026. You can only reverse an invoice that is posted; a parked one is deleted instead (B).

B · Delete a PARKED invoice — MIR4 (one document) or MIR6 (from a list)

#Do thisDetails
1/nMIR4 → Enter
2Enter Invoice Document No. (e.g. 5100001735) and Fiscal Year 2026 → EnterTitle shows the document is Parked.
3Switch to change mode: click the Display ↔ Change button (pencil/glasses icon) or press Ctrl+F1The fields become editable.
4Menu Invoice Document → Delete (or Shift+F2)
5Confirm the popup with YesStatus bar: “Document 51000xxxxx deleted”.
6Check: /nMIR6 → Company Code 1710, Fiscal Year 2026, tick Parked → F8The document is no longer listed.

Alternative (many at once): /nMIR6 → select parked documents (tick Parked, Entered by RPA) → F8 → select the row(s) → click the Delete (trash) icon → confirm.

C · Post a parked invoice yourself (instead of Approve in the app)

#Do thisDetails
1/nMIR4 → document number + 2026 → Enter → Ctrl+F1 (change mode)
2Click Simulate (optional) to see the accounting linesThe traffic light must be green (balance 0.00) to post.
3Click PostStatus bar: “Document no. 51000xxxxx created” (same number). If the variance is outside SAP's tolerance it posts with payment block R — visible on the Payment tab.

What the dashboard Reset does (so you can explain it)

  1. Finds every supplier invoice in SAP with the invoice number as Reference (table RBKP) whose header text starts with AP Agent — it never touches invoices other people keyed in.
  2. Posted → reversed exactly like section A (reason 01, posting date 30.04.2026). Parked → deleted exactly like section B.
  3. Clears the app's processed log, pending review and exception for that invoice.
Do NOT reverse the goods receipt (MIGO → Cancellation) or delete the purchase order (ME22N) for demo cleanup — that destroys the demo case. If it ever happens, re-create it with python sap_demo_setup.py --only S0x --force.

Reading the Purchase Order History tab (ME23N)

ME23N → PO → Item detail → tab Purchase Order History. Every goods receipt and every invoice against this PO line is listed, grouped by transaction type:

Sh. TextMeaningComes from
WEGoods receipt (mvt 101; a return shows 122 with a negative quantity)Our setup script (MIGO / MB03 shows it)
BzWEDelivery costs at goods receipt — the planned freight (condition FVA1) accrued when goods arrivedAutomatic with the GR
RE-LInvoice receipt for the goods (the supplier invoice line)Agent post / approve
BzReInvoice receipt for the delivery costs (the freight part of the invoice)Agent post / approve
Tr./Ev. … (yellow rows)Sub-totals per transaction type—

The minus sign (20-, 250.00-) means a reversal. Invoices come in pairs: e.g. 5100001674 RE-L 20 then 5100001682 RE-L 20- = posted, then reversed by a Reset. When the RE-L sub-total is 0, nothing is invoiced any more and the case can be run again. If the last line has no matching minus line, an invoice is still posted — reset it (A) before demoing.

Posting Date shows 04/30/2026 for every line because MM periods in company code 1710 are open only up to 04/2026 — expected.

What the dashboard tells you after a click

  • Run shows a live progress list, then a report card: every step it took (PO read from SAP, GR read, duplicate check, the 13 checks — failing ones in red), the decision, and what it did in SAP with the document number and the T-code to verify it (blue SAP: … hints).
  • Current status column (refreshes every 5 s, also after you approve/reject in the review tab):
    • Not run yet — nothing in the app or in SAP for this invoice.
    • Posted in SAP 51000… / Approved · posted in SAP 51000… — check in MIR4.
    • Parked in SAP 51000… · waiting for review — open the review (Pending Review page) to Approve or Reject.
    • Rejected · parked doc … deleted in SAP — MIR6 no longer lists it.
    • Duplicate … — the same invoice was already processed; nothing new was created in SAP.
    • Exception — no goods receipt in SAP — S13 by design.
    • Already posted/parked in SAP … (earlier run) — click Reset — SAP still holds an agent invoice from before (e.g. the app was restarted). Reset it first, otherwise Run reports a duplicate.
  • Reset shows exactly which SAP document was reversed (with the reversal number) or deleted.
